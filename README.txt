MINIMAL PIXELS — FRONTEND

Files:
- index.html   Main page markup
- style.css    Responsive layout, styling, and project mockups
- script.js    Mobile navigation, portfolio filters, and scroll reveals

How to run:
1. Extract the ZIP file.
2. Open index.html in your browser.

No framework or build step is needed. Google Fonts load from the internet; the page falls back to system fonts if unavailable.

Note: This is an original responsive frontend recreation inspired by the Minimal Pixels studio name and design-agency concept. The source website could not be directly inspected, so the exact original layout and copy may differ.
